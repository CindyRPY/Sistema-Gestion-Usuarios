## Almacenamiento de Datos

El sistema utiliza MongoDB como base de datos NoSQL para almacenar información de usuarios e incidentes viales.

La integración se realiza mediante PyMongo, permitiendo:

- Persistencia de datos.
- Gestión de usuarios.
- Almacenamiento de incidentes.
- Consultas de información.
- Actualización de registros.
- Eliminación de datos.

## Funcionalidades Implementadas

- Inicio de sesión y autenticación

- Gestión de usuarios

- Control de permisos por roles

- Registro de incidentes viales

- Clasificación por tipo de accidente

- Consumo de APIs externas

- Integración con MongoDB

- Persistencia de información

- Interfaz gráfica desarrollada con PySide6
